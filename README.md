# 提花机 TIHUAJI — 机构复刻 No.12

《天工开物·乃服》花机:双层结构——挽花工坐花楼提纤(经线按纹样分组提沉),
织工投梭引纬、打筘推纬,布面纹样逐纬生长(8 纬循环)。提沉-纹样一致性
载入断言。B 键查看总图与循环状态机。

## 机构与验算

```
尺寸(演示值):
  机架   织口居中,经轴/布轴两端;花楼高 2.05 后置
  经线   8 组分组提沉;纬距 0.045 m
  循环   一纬 = 提纤 0.7s → 投梭 0.9s → 打筘 0.8s

纹样(载入期断言):
  pattern = [1,0,2,0,3,0,2,1](八纬循环)
  模拟 24 纬:织纬计数恰 24、布纹[k] = pattern[k%8] 逐位一致
  布长 = 纬数 × 纬距
```
